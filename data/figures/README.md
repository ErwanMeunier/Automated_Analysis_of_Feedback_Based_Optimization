# Regenerated reviewer figures

`paper_kappa_0/` contains the primary experiment. `supplement_kappa_0p1/`
contains additional results with μ_f/L_f=0.1. Both use normalized L_f=1.

| File | Experiment |
|---|---|
| `paper_figure3.pdf` / `.png` | Raw worst-case gap versus constant step size at T=20 |
| `best_PEP_and_alpha_vs_T_split.pdf` / `.png` | Normalized worst-case performance and chosen step size versus horizon |
| `paper_figure2.pdf` / `.png` | Chosen step size and normalized performance versus L_A |
| `relative_improvement_vs_normA.pdf` / `.png` | Relative improvement against the uniform analytical design |

Each directory includes its selected-κ `best_points.csv`, `sampled_best.csv`,
`alpha_sweep.csv`, `relative_improvement.csv`, `group_coverage.csv`, and plotting
summary. Original reference inputs are in `data/reference/`; accepted overlays
are in `data/corrections/`. Work-directory names in the summary identify the
temporary prepared tables used for rendering; those tables are regenerated by
the script and are not needed to read the supplied plotted-value CSVs.

Run `julia --project=. scripts/reproduce_figures.jl` from the repository root
to regenerate all views. Default figures exclude uncertified analytical
estimates and omit missing designs. Optional diagnostic views that include
uncertified estimates mark them with red crosses.

For T=50 and L_A=0.7, the relative improvement is approximately 29.9% for
κ=0 and 38.9% for κ=0.1. The selected-κ `best_points.csv` gives the underlying
values for this comparison and other parameter choices.
